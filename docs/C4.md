# Enterprise IT Helpdesk Lab — C4 Architecture

> Source of truth: repo README (lab + portal + 20 tickets + PowerShell) and
> `internal-portal/README.md`. Portal is the software control plane INSIDE the
> lab project, not a separate project.

## C4-Context

```mermaid
C4Context
    title Helpdesk Lab — System Context
    Person(tech, "IT technician", "assets, tickets, onboarding")
    Person(staff, "Employee", "raises tickets, gets devices")
    System(lab, "Helpdesk Lab", "AD/GPO/DNS lab + portal + automation")
    System_Ext(ai, "OpenAI / Ollama / offline playbook", "copilot cascade")
    System_Ext(mini, "MiniERP", "incident receiver integration")
    Rel(tech, lab, "operates", "portal + RDP/PowerShell")
    Rel(staff, lab, "requests help", "portal")
    Rel(lab, ai, "diagnosis suggestions", "API/fallback")
    Rel(lab, mini, "fail-soft incident posts", "HTTP")
```

## C4-Container

```mermaid
C4Container
    title Helpdesk Lab — Containers
    Person(tech, "IT technician", "SPA dashboard")
    Container_Boundary(l, "Lab project") {
        Container(portal, "internal-portal", "Node/Express", "assets, ITIL, licenses, AI, audit")
        Container(py, "python-portal", "Flask", "isolated Flask mirror, 79 tests")
        Container(ps, "PowerShell automation", "scripts", "AD bulk, inventory, net diag")
        ContainerDb(store, "atomic JSON store", "files", "db.json + baseline restore")
    }
    System_Ext(ad, "AD/DNS/DHCP lab", "Windows Server 2022")
    Rel(portal, store, "persists atomically", "file")
    Rel(ps, ad, "provisions, audits", "WinRM/AD")
    Rel(portal, ad, "documents + integrates", "docs/API")
```
